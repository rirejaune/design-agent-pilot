# Задание 1. Старт: Claude Code, GitHub и первый проект

**Что получится:** на компьютере установлен Claude Code, у вас есть аккаунт на GitHub, свой
приватный репозиторий и проект, который агент ведёт сам: документирует сессии, делает
коммиты и отправляет их на GitHub.

**Время:** около часа.

---

## 1. Установи Claude Code

### macOS

Открой терминал: Программы → Утилиты → Терминал, или Cmd+Пробел → набери «Терминал». Выполни:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Нужна macOS 13.0 или новее.

### Windows

Нужна Windows 10 (версия 1809 и новее) или Windows 11.

1. Открой терминал: нажми Win → набери «Терминал» (или PowerShell) → Enter.
2. Сначала поставь Git для Windows. Claude Code работает через него:

   ```powershell
   winget install --id Git.Git -e
   ```

   Если `winget` не найден, скачай установщик с https://git-scm.com/download/win и
   прощёлкай его с настройками по умолчанию.
3. Закрой терминал, открой заново и установи Claude Code:

   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```

4. Ещё раз закрой и открой терминал, чтобы он увидел новую программу.

### Проверка (обе системы)

```
claude --version
```

Команда должна вывести номер версии. Утилита обновляется сама в фоне.

Для чтения и правки `.md`-файлов с разметкой удобно поставить Sublime Text или VS Code (есть
на обе системы).

Официальная документация, если что-то пойдёт не так: https://code.claude.com/docs/ru/quickstart

## 2. Вход в аккаунт — строго под VPN

Запусти:

```
claude
```

При первом старте откроется браузер для входа и подтверждения подписки (Pro / Max / Team /
Enterprise). **Логинься строго под VPN**, чтобы сайт открылся и не было бана. Раньше такие
случаи бывали. Как сейчас, неизвестно, но лучше перестраховаться.

После входа учётные данные сохраняются, повторно логиниться не придётся. Сменить аккаунт можно
командой `/login` в работающей сессии.

## 3. Заведи аккаунт на GitHub

Обычная регистрация на https://github.com, нужна только почта.

## 4. Создай тестовый репозиторий и токен доступа

1. Создай новый **приватный** репозиторий: кнопка **New**, имя любое, например `my-wiki`.
2. Создай токен, по которому Claude будет работать с репозиторием за тебя.

   Внимательно: по умолчанию GitHub предлагает новый тип токена (fine-grained), а удобнее
   всего **classic**.

   - Settings → Developer settings → Personal access tokens → **Tokens (classic)** →
     **Generate new token (classic)**.
   - **Expiration: No expiration.** По умолчанию GitHub ставит 30 дней. Если не поменять,
     токен протухнет через месяц, и Claude потеряет доступ к репозиторию.
   - В разрешениях (scopes) поставь галочку на всю группу **repo**. Это полные права на
     работу с репозиторием, их достаточно агенту.
   - Нажми **Generate token** и сразу скопируй токен. GitHub покажет его только один раз.
3. Сохрани токен в текстовый файл. **Токен — это как пароль, никому не показывай.**

## 5. Создай папку проекта

Создай папку в месте, откуда она точно не будет переезжать, и положи туда файл с токеном
(например, `github-token.txt`).

- **macOS:** например, `Projects/wiki` в домашней папке (`~/Projects/wiki`).
- **Windows:** например, `C:\Users\<ты>\Projects\wiki`. Не клади проект в OneDrive и на
  рабочий стол, если они синхронизируются с облаком: синхронизация мешает git.

## 6. Что такое `cd` и как перейти в папку проекта

Терминал — программа, в которой ты общаешься с компьютером текстом, без мышки и окон. В любой
момент терминал «стоит» в какой-то одной папке. Это называется **текущая рабочая директория**.

`cd` (change directory, «сменить папку») перемещает терминал в указанную папку. В Finder или
Проводнике ты двойным кликом заходишь в папку, чтобы видеть её содержимое, а в терминале то же
самое делает команда `cd` с путём к папке. Все следующие команды выполняются внутри этой
папки. Поэтому Claude Code нужно запускать из папки проекта: так он увидит лежащие там файлы.

### Как узнать полный путь к папке

**macOS:**

1. Самый простой: перетащи папку из Finder прямо в окно терминала, macOS сам подставит путь.
   Останется дописать перед ним `cd ` (с пробелом) и нажать Enter.
2. Правый клик по папке → зажми Option (⌥) → «Скопировать путь к …».
3. Меню Вид → «Показать панель пути»: внизу окна видна полная цепочка папок.

**Windows:**

1. Перетащи папку из Проводника в окно Терминала, путь подставится сам. Допиши перед ним
   `cd ` и нажми Enter.
2. Правый клик по папке → «Копировать как путь» (в Windows 10 — Shift + правый клик).
3. Кликни в адресную строку Проводника: там полный путь, его можно скопировать.

Если в пути есть пробелы, путь нужно взять в кавычки. Перетаскивание и «Копировать как путь»
ставят их сами.

### Пример

macOS:

```bash
cd ~/Projects/wiki
claude
```

Windows:

```powershell
cd "C:\Users\<ты>\Projects\wiki"
claude
```

Полезные команды для ориентации (работают на обеих системах):

- `pwd` — напечатает, в какой папке ты сейчас;
- `ls` — покажет список файлов в текущей папке.

## 7. Запусти Claude Code из папки проекта и настрой проект

Как только увидишь приглашение Claude, скажи ему обычным языком:

- В папке лежит файл `github-token.txt` с токеном для GitHub. Пусть настроит git для проекта и
  сам ведёт версионирование: коммиты и push на GitHub.
- Попроси записать в `CLAUDE.md` постоянные правила проекта:
  - в конце каждой сессии строго документировать сессию, делать коммит и пушить на GitHub;
  - вести `worklog.md` для передачи результатов сессии другим агентам;
  - добавить `github-token.txt` в `.gitignore`, чтобы токен никогда не попал в репозиторий на
    GitHub;
  - общаться на русском языке;
  - не грузить техническими деталями, объяснять простыми словами;
  - любые свои пожелания.
- Затем дай основное задание, например создать структуру онтологизированной вики на
  интересную тебе тему, которую вы будете вести долго. Работай с ним, проси задавать
  уточняющие вопросы, согласуй структуру файлов и разделов.

## 8. Рабочий цикл

Заверши первую сессию. Дальше каждая сессия идёт так:

1. Открой терминал.
2. Перейди в папку проекта: `cd ~/Projects/wiki` на macOS, `cd "C:\Users\<ты>\Projects\wiki"`
   на Windows (или перетащи папку, как в шаге 6).
3. Введи `claude`.
4. Напиши обычным языком: «Ознакомься с контекстом вики, worklog и CLAUDE.md» и свои
   пожелания на сегодня.

Полезные команды внутри сессии:

- `/help` — справка по возможностям;
- `/clear` — очистить контекст перед новой задачей;
- `/login` — сменить аккаунт.

## Проверь себя

- [ ] `claude --version` выводит номер версии.
- [ ] На GitHub есть приватный репозиторий, и в нём видны коммиты агента.
- [ ] Файла с токеном **нет** на GitHub (открой репозиторий в браузере и проверь).
- [ ] В репозитории есть `CLAUDE.md` с твоими правилами и `worklog.md` с записью о первой
      сессии.
- [ ] Ты начал вторую сессию по циклу из шага 8, и агент рассказал, на чём вы остановились.
