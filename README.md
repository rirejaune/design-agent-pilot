# design-agent-pilot

Домашние задания пилотного потока: как дизайнеру формализовать свой дизайн так, чтобы агент
собирал интерфейс по вашим правилам, а не по усреднённому шаблону.

## Задания

| № | Задание | Что получится |
|---|---|---|
| 1 | [Старт: Claude Code, GitHub, первый проект](homework/01-start/README.md) | агент установлен, свой репозиторий, первая сессия |
| 2 | [Скафолд: сервер, сетка, токены, ритм](homework/02-scaffold/README.md) | своя маленькая дизайн-система и лендинг, собранный агентом |

Каждое задание написано для macOS и Windows. Где шаги различаются, это отмечено.

## Как пользоваться с агентом

Задания можно отдавать агенту прямо ссылкой или файлом, например:

> Прочитай https://github.com/rirejaune/design-agent-pilot/blob/main/homework/02-scaffold/README.md
> и проведи меня по заданию шаг за шагом.

Правила для агента, который помогает ученику, — в [CLAUDE.md](CLAUDE.md).
